工具介紹

今天的三位主角

🤖
Claude Code

Anthropic 出品的 CLI Coding Agent，擅長長文脈理解與多步驟任務執行。

⚡
Codex

OpenAI 推出的雲端 Coding Agent，可直接在沙盒環境執行程式並自動修正。

🚀
Anti-Gravity 2.0

新世代 Agentic IDE，主打多 Agent 協作與視覺化任務流程，2.0 版大幅強化推理能力。

工具 1 / 3

Claude Code

核心優勢

  • 超長 context window，一次讀入整份旅遊需求文件
  • Extended Thinking 模式，複雜行程邏輯推理更可靠
  • 直接在終端機操作本地檔案，輸出 .md / .csv / .ics
  • 支援 MCP，可串接 Google Maps、Notion 等外部工具
  • 與 Cowork、Claude Chat 的連結整合最為流暢
旅遊應用場景

用自然語言描述「五天京都行，預算 3 萬，偏好文化古蹟」， Claude Code 自動爬梳景點資料、排出最佳動線、輸出可匯入行事曆的 .ics 檔。 搭配 Cowork 協作模式，可以同步和同行旅伴共同修訂行程。

個人心得

目前覺得 Claude Code 是三者中最全面的工具。與 Cowork 和 Chat 的連結性最好，實際做旅遊規劃時幾乎不需要切換平台，整個工作流都在 Claude 生態內完成。目前主要也是用 Claude Code 搭配 Claude Design 來處理這類任務，相當夠用。

工具 2 / 3

Codex

核心優勢

  • 雲端沙盒環境，無需本地設定直接執行程式
  • 非同步任務：丟出需求後可去做別的事，稍後回來取結果
  • 自動 commit / PR，產出物直接進版本控制
  • 多任務並行，同時跑多個旅遊子任務
  • 執行速度快，適合需要快速產出初稿的場景
旅遊應用場景

同時丟出「找東京飯店比價」「規劃大阪一日遊」「整理簽證申請步驟」 三個任務，Codex 並行處理後統一回傳結果，大幅縮短等待時間。

個人心得

速度蠻快的，這點令人滿意。但目前感覺對外的連結性沒那麼好，在需要串接外部工具或服務的旅遊任務上，整合能力還比不上 Claude Code。適合做獨立、單純的快速任務。

工具 3 / 3

Anti-Gravity 2.0

核心優勢

  • 多 Agent 協作架構，不同 Agent 分工執行子任務
  • 視覺化任務流程圖，整個旅遊規劃進度一目瞭然
  • 2.0 版強化推理引擎，複雜約束條件處理更精準
  • 介面設計獨特，操作體驗與其他工具明顯不同
  • 執行速度快，視覺化任務表現值得期待
旅遊應用場景

規劃跨國多城市行程時，不同 Agent 分別負責交通、住宿、景點， 最後由主 Agent 整合衝突並輸出最終行程。 獨特的視覺化介面或許特別適合用來呈現行程地圖與時間軸。

個人心得

目前還在學習摸索中，但介面蠻特別的，速度也很快。初步感覺針對視覺化任務可能會更好用，有待後續更多使用後再做觀察與評估。

實戰

我的 AI 旅遊規劃工作流程

1
需求輸入 — Claude Code

用自然語言描述完整旅遊需求，Claude Code 拆解成結構化任務清單，輸出 markdown 規格文件。

2
資料蒐集 — Codex

將資料蒐集任務丟給 Codex 非同步執行：景點資料、飯店比價、交通時刻表同步進行。

3
行程整合 — Anti-Gravity 2.0

用 Anti-Gravity 的多 Agent 架構整合所有資料，自動解決時間衝突，輸出最終可執行行程。

從 Google 到 Microsoft Office，一次介紹好用的 AI 插件。

Google AI 工具

NotebookLM & Gemini

📓
NotebookLM
  • 上傳 PDF、文件、網址，AI 自動整理成知識庫
  • 一鍵生成 Podcast 音頻，兩位 AI 主持人對談式摘要
  • 對文件內容直接提問，引用來源清楚標示
  • 自動產出心智圖、學習指南、FAQ
旅遊應用： 把旅遊指南、部落格文章全部丟進去，讓 NotebookLM 幫你整理成問答式的旅遊知識庫，出發前快速複習。
🧩 Chrome 擴充功能
▸
Kortex-NotebookLM — 將網頁、文章一鍵存入 Kortex 知識庫並同步至 NotebookLM
▸
NotebookLM 網頁匯入器 — 瀏覽旅遊文章時直接匯入當前頁面，無需複製貼上
▸
WebSync for NotebookLM — 自動同步書籤與常用網頁到 NotebookLM 資料來源
✨
Gemini
  • 深度整合 Google Workspace（Docs、Sheets、Gmail、Meet）
  • Google Maps、Search、Flights 即時資訊串接
  • 多模態輸入：文字、圖片、語音、影片皆支援
  • Deep Research 模式，自動彙整網路資料成長篇報告
旅遊應用： 在 Gmail 草擬旅館訂房信件、在 Google Docs 同步整理行程、用 Deep Research 一次查完目的地的交通與物價資訊。
熱門插件

其他值得關注的 AI 工具

🤖 ChatGPT / GPTs

Custom GPTs 讓任何人打造專屬 AI 助理。可建立「行前檢查表 Bot」「簽證攻略 Bot」等，直接分享給旅伴使用。

🔍 Perplexity AI Companion

Chrome 擴充功能版 AI 搜尋引擎，瀏覽任何頁面時側邊欄即時提問。查即時資訊（入境規定、票價）特別好用。

⚖️ CompareAI

同一個問題同時送給 ChatGPT、Claude 等多個 AI，左右並排顯示回答。快速找出哪個 AI 對旅遊問題回答最準確。

✨ Enhancer 4 Google

在 Google 搜尋結果旁自動顯示 AI 摘要回答，搜旅遊資訊時不用再逐頁點開，節省大量瀏覽時間。

🎨 Gamma

AI 簡報製作工具。輸入主題或大綱自動生成設計精美的投影片，分享旅遊心得比 PowerPoint 快上數倍。

🗺️ Napkin AI

把文字自動轉成視覺化圖表與示意圖。將旅遊行程貼入，立即產出時間軸或流程圖，讓簡報更清楚易懂。

Office 裡的 AI 插件

📝 Word Copilot

草擬旅遊行程文件、自動摘要長篇攻略、依照你的語氣改寫內容。從空白頁到完整文件只需幾秒。

✦ 草稿生成  ✦ 改寫潤稿
📊 Excel Copilot

用自然語言操作試算表：「幫我算每人平均費用」「標示超出預算的項目」，不用寫公式也能完成複雜分析。

✦ 預算試算  ✦ 自動圖表
🖼️ PowerPoint Designer

貼入文字或圖片後自動推薦版面設計，AI 幫你配色與排版。旅遊照片 + 行程摘要秒變精緻簡報。

✦ 自動排版  ✦ 設計建議
📧 Outlook Copilot

一鍵摘要長信件串、草擬訂房確認信、自動整理行程相關郵件。旅遊前後的大量郵件不再是負擔。

✦ 信件摘要  ✦ 快速草稿
💬 Teams Copilot

會議結束後自動生成逐字稿與行動項目摘要。團體旅遊討論會議不用再自己做紀錄，直接讓 AI 整理決議事項。

✦ 會議摘要  ✦ 待辦清單
💡

Microsoft 365 Copilot 需要訂閱授權，但整合在熟悉的 Office 介面內，對於已在使用 Microsoft 套件的人來說學習成本幾乎為零。
